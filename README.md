# Site officiel ISee — GitHub Pages

Site vitrine ISee avec le logo fourni par le créateur.

## Mise à jour

Dans le dépôt GitHub `thenornor/isee`, importer **les 7 fichiers HTML/CSS/logo/README à la racine** via `Add file → Upload files` et confirmer `Commit changes`. Lors du remplacement, GitHub met à jour les fichiers existants.

Le site public : https://thenornor.github.io/isee/

## Avant lancement public

Les documents juridiques sont des **brouillons** : vérifier identité et adresse de l’éditeur, mineurs, base légale, hébergement, conservation, suppression effective des données, modération et publication de la localisation. Ne pas considérer les textes comme validés.
